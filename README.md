# Blagodat songbook bundle

The encrypted songbook of Slavic Grace Baptist Church
([blagodat.com](https://blagodat.com/)), read by the
[Songbook](https://github.com/gbc-youth/songbook) app.

Everything here is AES-256-GCM encrypted and unreadable without the church's
join link. It is published automatically from a private repository; do not edit
it by hand.
